# Rock Paper Scissors on Python

A console version of the game Rock Paper Scissors written on Python. The gameplay involves entering your choice and seeing the result of the face-off against the bot.

## Used libs and languages

* Python with Random lib

## How to run

1. **Download and install Python on your PC.**
2. **Download .py file.**
3. **On Windows: run it through double-click. On Linux Mint: open the folder you've downloaded the .py file in terminal and run:** `python3 RPS.py.`
4. **Prompt item you're going to use in the game.**
5. **Once you had enough, just enter 'exit'.**
